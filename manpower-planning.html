01 / The planning problem

Installation demand is shaped by more than project count.

Carpenters need to be lined up before a project reaches site. But installation dates move. Production can run late, and payment or site readiness can push the start back further. So the plan needs an early estimate, and a way to update it when better information comes in.

02 / Model logic

Two forecasts, refined as the project progresses.

Design releaseCapture facia SFT and project city.
Long-range estimateProduction release + 35 days.
Production completeReplace the early estimate with actual completion.
Short-range estimateActual completion + 10 days.
Readiness checkAdjust for payment clearance and site readiness.

The 35-day and 10-day intervals are planning assumptions, not guaranteed service levels. Client payment and site readiness can move the expected installation date.

03 / Workload assumptions

Estimate workload, then translate it into crew demand.

Workload calculation

Estimated carpenter mandays use facia area with a 10% allowance for rework.

Mandays = (Facia SFT × 1.10) ÷ 20

Assumed productivity: 20 SFT per carpenter per day.

Installation sequence

  • Segregation and Phase 1: about 73% of the project's mandays (16 parts in 22).
  • Production and site-work gap: 8–20 calendar days, with no carpenter demand in this simplified model.
  • Phase 2 and rework: the remaining 27% (6 parts in 22).

The 16:6 split divides each project's estimated mandays between the two phases. Real deployment varies with scope and site conditions.

Initial work block ~73% of a project's mandays · Segregation + Installation Phase 1
Non-carpenter gap 8–20 days Additional production, dispatch and site work
Final work block ~27% of a project's mandays · Installation Phase 2 + rework

Current status

This is a model and a demo built on synthetic data. It isn't a prediction engine. It's plain arithmetic on a few assumptions. Before real use, those assumptions need checking against past projects: facia area, actual mandays, installation dates, production completion, payment clearance and site readiness.

06 / What I learned

Simple models earn trust faster.

Revise, don't just predict

A forecast gets useful when it updates. Swapping the early estimate for actual production completion matters more than a cleverer first guess.

Show the formula

Area × 1.1 ÷ 20 is something a team lead can check in their head. That makes it easier to question, and easier to adopt.

Readiness is the real variable

Workload is fairly predictable. Payment clearance and site readiness are what actually move the dates.
